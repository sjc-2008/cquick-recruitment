## 任务 2：图片读取

- 图片来源：脚本生成的测试图（橙色圆形目标）
- 尺寸：宽 640、高 480
- shape：(480, 640, 3)
- dtype：uint8

### 理解

- **shape 含义**：`(高, 宽, 通道数)`，即 480 行、640 列、3 个通道（BGR）。
- **dtype 含义**：`uint8` 表示每个像素通道值用 8 位无符号整数存储，范围 0~255。
- **BGR vs RGB**：OpenCV 默认按 BGR 顺序存储彩色图，与常见的 RGB 顺序相反。示例像素 `[17, 131, 255]` 中，B=17、G=131、R=255，即该点偏橙色（R 最大）。

## 任务 3：图像处理

| 操作 | 目的 | 说明 |
| --- | --- | --- |
| 灰度化 | 把彩色图转成单通道灰度图 | 通道数从 3 变为 1，只保留亮度信息 |
| HSV 转换 | 分离色调/饱和度/明度 | 便于按颜色做分割 |
| 阈值分割 | 生成二值图（黑白） | 用阈值区分前景和背景 |

### 参数对比

- 方案 A：固定阈值 127，非零像素数 25738。
- 方案 B：Otsu 自动阈值，非零像素数 25787。

两者结果接近，说明这张图的前景/背景在阈值 127 附近区分度一般，Otsu 会自动计算一个更合适的阈值。

### 失败案例 / 局限

阈值分割对光照和背景颜色敏感：如果目标与背景亮度接近，固定阈值很难分开它们。真实场景中光照变化、阴影、背景同色都会导致分割失败。
